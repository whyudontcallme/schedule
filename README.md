# Моё расписание 📅

Улучшенная мобильная версия студенческого расписания (сентябрь–декабрь 2026).

## Что внутри
- **Сегодня / Завтра / Неделя / Поиск** — нижнее меню для телефона
- **Сейчас идёт / следующая пара** — живой прогресс и обратный отсчёт
- **Чёт / нечет** — автоопределение от 31.08.2026 + ручной переключатель
- **Тёмная/светлая тема**, крупные кнопки, работает офлайн (PWA)
- Кнопка **«Скопировать день»** — удобно кинуть в чат группы

## Открыть с телефона
1. Включи GitHub Pages: Settings → Pages → Deploy from branch → `main` → `/ (root)`
2. Открой выданную ссылку вида `https://<твой-ник>.github.io/<репо>/` с телефона
3. В браузере: Поделиться → На экран «Домой» — будет как приложение

## Локально
Просто открой `index.html` или запусти `python3 -m http.server` в папке.
